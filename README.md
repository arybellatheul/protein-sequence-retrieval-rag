## My Contribution

As part of the University of Rhode Island AI Lab, I focused on
developing and testing the retrieval component of a larger protein
detection and annotation research project.

My work included:

- Building a prototype vector database using Chroma
- Generating protein sequence embeddings using gLM2
- Structuring an embedding → storage → retrieval workflow
- Performing similarity-based queries
- Validating nearest-neighbor retrieval behavior
- Exploring FAISS and Qdrant as potential alternatives
- Contributing to early database architecture and scalability decisions
